# Token

**Related notes:** [[Keyword]], [[Modifier]], [[Literal]], [[Operator]], [[Separators]], [[Comment]], [[Annotation]]

---

A **token** is the smallest unit of meaningful code in a programming language. During compilation, the Java compiler breaks your source code into these tokens to analyze and understand the program's structure.

---

### Example Breakdown

In the statement `int x = 5;`, the individual tokens are:

1. `int`
2. `x`
3. `=`
4. `5`
5. `;`

---

### Types of Tokens in Java

Java tokens are categorized into several specific types:

| **Token Type**  | **Description**                                                                     |
| --------------- | ----------------------------------------------------------------------------------- |
| **Keywords**    | Reserved words with predefined meanings in Java.                                    |
| **Identifiers** | Names used to identify **variables**, **methods**, **classes**, and other entities. |
| **Literals**    | Fixed constant values written directly in the code.                                 |
| **Operators**   | Symbols used to perform operations on operands.                                     |
| **Separators**  | Help define the structure of the code.                                              |
| **Comments**    | Text that serves as documentation.                                                  |
