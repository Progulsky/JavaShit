# Code_Block

**Related notes:** [[Method]], [[Class]], [[Conditional Logic]], [[Loop]], [[Exception]], [[Scope]], [[Statement]]

---

A **code block** (also known as a block statement or compound statement) is a fundamental structural element in Java. It is used to group zero (e.g., `{ }`) or more **Statements** together, treating them as a single unit. It defines a scope

```
// EXAMPLE
{
    // This is a code block
    int x = 5;
    System.out.println(x);
}
```
