# Literal

**Related notes:** [[Expression]], [[Token]], [[Variable]], [[Operator]]

---

A **literal** is a fixed value written directly in the source code of a program. It represents constant data that is assigned to **variables** or used in **expressions**. Essentially, literals are the actual values — such as numbers, characters, and strings — written into your code.

---

### Examples of Literals

|**Data Type**|**Literal Example**|
|---|---|
|**Integer**|`5`|
|**String**|`"Hi"`|
|**Floating-point**|`-0.34`|
|**Boolean**|`False`|
